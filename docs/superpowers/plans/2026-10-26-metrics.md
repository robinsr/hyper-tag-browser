# Performance Metrics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the OpenTelemetry-based metrics with a small in-house recorder that persists span and timing data to a local `metrics.sqlite`, and instrument the indexing pipeline and every SQL statement.

**Architecture:** Spans (low-volume, named pipeline steps) emit `OSSignposter` intervals for Instruments and are written raw. Timings (high-volume: per-file steps, per-SQL-statement) go into an in-memory aggregator with fixed log-scale buckets, flushed every 60 s into one row per `(name, tags)` per window. Each window links to a DB-size snapshot (row counts and file sizes) so latency can be analyzed against database growth.

**Tech Stack:** Swift 6 (app target), Swift 5 mode (test target), macOS 15, GRDB 7.9, Factory 2.4.12, `Synchronization.Mutex`, `OSSignposter`, Swift Testing + Nimble 14.

**Spec:** `docs/superpowers/specs/2026-10-26-metrics-design.md`

## Global Constraints

- Recording is always on in all builds; `DevFlags.metrics_disable` disables it (takes effect at next launch).
- Store location: `AppLocation.appSupport.appending("metrics.sqlite")` (`~/Library/Application Support/HyperTagBrowser/metrics.sqlite`).
- Flush every 60 s and at `applicationWillTerminate` (termination budget 200 ms).
- DB snapshot: at session start, then during a flush with data only if ≥ 300 s since the last one. Count base tables only — never views.
- Retention: delete `timings` and `spans` older than 90 days at launch.
- Bucket upper bounds (ms), exactly: `0.05, 0.1, 0.25, 0.5, 1, 2.5, 5, 10, 25, 50, 100, 250, 500, 1000, 10000, +∞`.
- Cardinality cap: 5,000 distinct `(name, tags)` keys per window; overflow goes to `metrics.overflow`.
- SQL hashes: FNV-1a 64 of the normalized SQL, 16 lowercase hex chars. Never use Swift `hashValue`.
- Tags must be low-cardinality: never put file paths, ids, or user-entered values in tags.
- Metrics code never throws to callers and never crashes the app.
- Tests must never write to the real `metrics.sqlite`: the factory returns `NoopMetricsRecorder` when `FactoryContext.current.isTest`.
- Formatting: `HyperTagBrowser/.swift-format` (2-space indent, 100 cols, no semicolons, no force-unwraps). New files start with `// created on 10/26/26 by robinsr`.
- Commit messages: one-sentence summary line, blank line, then one bullet per file or logical group (see `~/.claude/CLAUDE.md`).
- New files under `HyperTagBrowser/App/` and `HyperTagBrowserTests/App/` or `HyperTagBrowserTests/TestSupport/` are added to their targets automatically (synchronized folders in `project.xcproj`); no project edits are needed except Task 4's package removal.

**Deviations from the spec, decided while planning:**
- `gauge(...)` is dropped from the protocol: nothing in this plan uses it (YAGNI).
- The span type is `MetricSpan`, not `Span`. A type named `Span` in the app module would shadow `OpenTelemetryApi.Span` in files that still import OTel during Tasks 1–3.
- `MetricsFlusher` is not a separate type: the flush logic is `DefaultMetricsRecorder.flush(now:)` plus a periodic `Task`.
- Rollout steps 1 and 2 of the spec are merged in Task 4, because the new `MetricsRecorder` protocol has the same name as the old one.
- `fs.xattr.assign` is added: `indexContents` assigns new file IDs (an xattr write) during listing.
- `MetricsSink` uses explicit methods per write kind instead of `write(aggregates:snapshot:)`.

```swift
import Foundation


/// Low-cardinality labels attached to spans and timings. Never put paths, ids, or user input here.
typealias MetricTags = [String: String]


extension Dictionary where Key == String, Value == String {
  /// JSON object with sorted keys, so equal tag sets always produce identical text.
  var canonicalJSON: String {
    let encoder = JSONEncoder()
    encoder.outputFormatting = [.sortedKeys, .withoutEscapingSlashes]
    guard let data = try? encoder.encode(self) else { return "{}" }
    return String(decoding: data, as: UTF8.self)
  }
}


extension ContinuousClock.Instant {
  /// Milliseconds elapsed between this instant and now.
  var elapsedMs: Double {
    (ContinuousClock.now - self).milliseconds
  }
}


extension Duration {
  var milliseconds: Double {
    let parts = components
    return Double(parts.seconds) * 1_000 + Double(parts.attoseconds) / 1e15
  }
}
```

```swift
// created on 10/26/26 by robinsr

import Foundation
import Synchronization


enum TimingBuckets {
  /// Inclusive upper bounds in milliseconds. Fixed so bucket counts can be summed across
  /// windows and sessions. Changing these requires a new `timings` schema version.
  static let upperBoundsMs: [Double] = [
    0.05, 0.1, 0.25, 0.5, 1, 2.5, 5, 10, 25, 50, 100, 250, 500, 1_000, 10_000, .infinity,
  ]

  static func index(for ms: Double) -> Int {
    upperBoundsMs.firstIndex { ms <= $0 } ?? upperBoundsMs.count - 1
  }
}


struct TimingKey: Hashable, Sendable {
  let name: String
  let tags: MetricTags
}


struct TimingAggregate: Equatable, Sendable {
  let key: TimingKey
  var count = 0
  var sumMs = 0.0
  var minMs = Double.infinity
  var maxMs = 0.0
  var buckets = [Int](repeating: 0, count: TimingBuckets.upperBoundsMs.count)

  init(key: TimingKey) {
    self.key = key
  }

  mutating func add(_ ms: Double) {
    count += 1
    sumMs += ms
    minMs = min(minMs, ms)
    maxMs = max(maxMs, ms)
    buckets[TimingBuckets.index(for: ms)] += 1
  }
}


/// Accumulates timings per `(name, tags)` until drained by a flush.
final class TimingAggregator: Sendable {
  static let overflowName = "metrics.overflow"

  private let maxKeys: Int
  private let state = Mutex<[TimingKey: TimingAggregate]>([:])

  init(maxKeys: Int = 5_000) {
    self.maxKeys = maxKeys
  }

  func record(_ name: String, ms: Double, tags: MetricTags = [:]) {
    state.withLock { aggregates in
      var key = TimingKey(name: name, tags: tags)

      if aggregates[key] == nil && aggregates.count >= maxKeys {
        key = TimingKey(name: Self.overflowName, tags: [:])
      }

      aggregates[key, default: TimingAggregate(key: key)].add(ms)
    }
  }

  func drain() -> [TimingAggregate] {
    state.withLock { aggregates in
      defer { aggregates.removeAll(keepingCapacity: true) }
      return Array(aggregates.values)
    }
  }
}
```

```swift
// created on 10/26/26 by robinsr

import Foundation
import OSLog
import Synchronization


enum SpanOutcome: String, Sendable {
  case ok
  case error
}


/// A completed span, as persisted.
struct SpanRecord: Equatable, Sendable {
  let id: String
  let traceId: String
  let parentId: String?
  let name: String
  let startedAt: Date
  let durationMs: Double
  let outcome: SpanOutcome
  let tags: MetricTags
}


/// Starts spans and receives their records when they stop.
///
/// `@unchecked Sendable`: `OSSignposter` is documented as thread-safe.
struct SpanEmitter: @unchecked Sendable {
  let signposter: OSSignposter
  let onStop: @Sendable (SpanRecord) -> Void

  static let silent = SpanEmitter(signposter: .disabled, onStop: { _ in })

  func start(_ name: StaticString, tags: MetricTags, parent: MetricSpan?) -> MetricSpan {
    MetricSpan(name: name, tags: tags, parent: parent, emitter: self)
  }
}


/// A named, timed interval. Shows in Instruments (Points of Interest) and is written to
/// `metrics.sqlite` as one row when stopped. Use for low-volume steps only; use timings for
/// anything that runs per file or per statement.
final class MetricSpan: Sendable {
  let id: String
  let traceId: String
  let parentId: String?
  let name: StaticString
  let startedAt: Date

  private let start: ContinuousClock.Instant
  private let emitter: SpanEmitter
  private let state: Mutex<State>

  private struct State {
    var tags: MetricTags
    var interval: OSSignpostIntervalState?
    var stopped = false
  }

  fileprivate init(name: StaticString, tags: MetricTags, parent: MetricSpan?, emitter: SpanEmitter) {
    let id = UUID().uuidString
    self.id = id
    self.traceId = parent?.traceId ?? id
    self.parentId = parent?.id
    self.name = name
    self.startedAt = Date()
    self.start = ContinuousClock.now
    self.emitter = emitter

    let signposter = emitter.signposter
    let interval = signposter.beginInterval(name, id: signposter.makeSignpostID())
    self.state = Mutex(State(tags: tags, interval: interval))
  }

  func tag(_ key: String, _ value: some CustomStringConvertible) {
    state.withLock { $0.tags[key] = value.description }
  }

  func child(_ name: StaticString, tags: MetricTags = [:]) -> MetricSpan {
    emitter.start(name, tags: tags, parent: self)
  }

  /// Ends the span. Calls after the first are ignored.
  func stop(outcome: SpanOutcome = .ok) {
    let durationMs = start.elapsedMs
    let name = self.name
    let signposter = emitter.signposter

    let tags: MetricTags? = state.withLock { state in
      guard !state.stopped else { return nil }
      state.stopped = true

      if let interval = state.interval {
        signposter.endInterval(name, interval)
      }

      return state.tags
    }

    guard let tags else { return }

    emitter.onStop(
      SpanRecord(
        id: id,
        traceId: traceId,
        parentId: parentId,
        name: String(describing: name),
        startedAt: startedAt,
        durationMs: durationMs,
        outcome: outcome,
        tags: tags
      ))
  }

  /// Runs `body`, then stops the span: `.ok` on return, `.error` if `body` throws.
  func measure<T>(_ body: (MetricSpan) throws -> T) rethrows -> T {
    do {
      let result = try body(self)
      stop()
      return result
    } catch {
      stop(outcome: .error)
      throw error
    }
  }
}


/// Holds stopped spans until the next flush.
final class SpanBuffer: Sendable {
  private let records = Mutex<[SpanRecord]>([])

  func append(_ record: SpanRecord) {
    records.withLock { $0.append(record) }
  }

  func drain() -> [SpanRecord] {
    records.withLock { records in
      defer { records.removeAll() }
      return records
    }
```

```swift
import Foundation
import GRDB
import System


/// Writes metrics to a dedicated SQLite file, separate from the index database.
final class SQLiteMetricsSink: MetricsSink {
  let database: DatabaseQueue

  init(queue: DatabaseQueue) throws {
    self.database = queue
    try Self.migrator.migrate(queue)
  }

  convenience init(path: FilePath) throws {
    try self.init(queue: DatabaseQueue(path: path.string))
  }

  /// Opens the sink at `path`. If the file can't be opened or migrated, it is renamed to
  /// `<name>.bad-<unix time>` and a fresh file is created. Returns nil if that fails too.
  static func openOrRecover(at path: FilePath, logger: CustomLogger) -> SQLiteMetricsSink? {
    do {
      return try SQLiteMetricsSink(path: path)
    } catch {
      logger.emit(.error, "metrics.sqlite is unusable, setting it aside: \(error)")
    }

    let fileName = path.lastComponent?.string ?? "metrics.sqlite"
    let badPath = path.removingLastComponent()
      .appending("\(fileName).bad-\(Int(Date().timeIntervalSince1970))")

    do {
      try FileManager.default.moveItem(atPath: path.string, toPath: badPath.string)

      for suffix in ["-wal", "-shm"] {
        try? FileManager.default.removeItem(atPath: path.string + suffix)
      }

      return try SQLiteMetricsSink(path: path)
    } catch {
      logger.emit(.error, "metrics.sqlite recovery failed: \(error)")
      return nil
    }
  }

  private static var migrator: DatabaseMigrator {
    var migrator = DatabaseMigrator()

    migrator.registerMigration("v1") { db in
      try db.execute(
        sql: """
          CREATE TABLE sessions (
            id            TEXT PRIMARY KEY,
            started_at    DATETIME NOT NULL,
            ended_at      DATETIME,
            app_version   TEXT NOT NULL,
            build_number  TEXT NOT NULL,
            os_version    TEXT NOT NULL,
            main_db_name  TEXT NOT NULL
          );

          CREATE TABLE spans (
            id            TEXT PRIMARY KEY,
            session_id    TEXT NOT NULL REFERENCES sessions(id),
            trace_id      TEXT NOT NULL,
            parent_id     TEXT,
            name          TEXT NOT NULL,
            started_at    DATETIME NOT NULL,
            duration_ms   DOUBLE NOT NULL,
            outcome       TEXT NOT NULL,
            tags          TEXT NOT NULL
          );
          CREATE INDEX spans_trace ON spans(trace_id);
          CREATE INDEX spans_name_time ON spans(name, started_at);

          CREATE TABLE db_snapshots (
            id            INTEGER PRIMARY KEY,
            session_id    TEXT NOT NULL REFERENCES sessions(id),
            taken_at      DATETIME NOT NULL,
            file_bytes    INTEGER NOT NULL,
            wal_bytes     INTEGER NOT NULL,
            row_counts    TEXT NOT NULL
          );

          CREATE TABLE timings (
            id            INTEGER PRIMARY KEY,
            session_id    TEXT NOT NULL REFERENCES sessions(id),
            snapshot_id   INTEGER REFERENCES db_snapshots(id),
            window_start  DATETIME NOT NULL,
            window_secs   INTEGER NOT NULL,
            name          TEXT NOT NULL,
            tags          TEXT NOT NULL,
            count         INTEGER NOT NULL,
            sum_ms        DOUBLE NOT NULL,
            min_ms        DOUBLE NOT NULL,
            max_ms        DOUBLE NOT NULL,
            buckets       TEXT NOT NULL
          );
          CREATE INDEX timings_name_time ON timings(name, window_start);

          CREATE TABLE sql_statements (
            hash           TEXT PRIMARY KEY,
            kind           TEXT NOT NULL,
            normalized_sql TEXT NOT NULL,
            first_seen     DATETIME NOT NULL
          );
          """)
    }

    return migrator
  }

  func begin(session: MetricsSession) throws {
    try database.write { db in
      try db.execute(
        sql: """
          INSERT INTO sessions
            (id, started_at, app_version, build_number, os_version, main_db_name)
          VALUES (?, ?, ?, ?, ?, ?)
          """,
        arguments: [
          session.id, session.startedAt, session.appVersion, session.buildNumber,
          session.osVersion, session.mainDbName,
        ])
    }
  }

  func end(sessionId: String, at date: Date) throws {
    try database.write { db in
      try db.execute(
        sql: "UPDATE sessions SET ended_at = ? WHERE id = ?", arguments: [date, sessionId])
    }
  }

  func write(spans: [SpanRecord], sessionId: String) throws {
    guard !spans.isEmpty else { return }

    try database.write { db in
      for span in spans {
        try db.execute(
          sql: """
            INSERT INTO spans
              (id, session_id, trace_id, parent_id, name, started_at, duration_ms, outcome, tags)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
            """,
          arguments: [
            span.id, sessionId, span.traceId, span.parentId, span.name, span.startedAt,
            span.durationMs, span.outcome.rawValue, span.tags.canonicalJSON,
          ])
      }
    }
  }

  func write(snapshot: DBSnapshot, sessionId: String) throws -> Int64 {
    try database.write { db in
      try db.execute(
        sql: """
          INSERT INTO db_snapshots (session_id, taken_at, file_bytes, wal_bytes, row_counts)
          VALUES (?, ?, ?, ?, ?)
          """,
        arguments: [
          sessionId, snapshot.takenAt, snapshot.fileBytes, snapshot.walBytes,
          Self.json(snapshot.rowCounts),
        ])
      return db.lastInsertedRowID
    }
  }

  func write(
    timings: [TimingAggregate], sessionId: String, snapshotId: Int64?, windowStart: Date,
    windowSecs: Int
  ) throws {
    guard !timings.isEmpty else { return }

    try database.write { db in
      for timing in timings {
        try db.execute(
          sql: """
            INSERT INTO timings
              (session_id, snapshot_id, window_start, window_secs, name, tags,
               count, sum_ms, min_ms, max_ms, buckets)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            """,
          arguments: [
            sessionId, snapshotId, windowStart, windowSecs, timing.key.name,
            timing.key.tags.canonicalJSON, timing.count, timing.sumMs, timing.minMs,
            timing.maxMs, Self.json(timing.buckets),
          ])
      }
    }
  }

  func write(statements: [SQLStatementInfo], firstSeen: Date) throws {
    guard !statements.isEmpty else { return }

    try database.write { db in
      for statement in statements {
        try db.execute(
          sql: """
            INSERT OR IGNORE INTO sql_statements (hash, kind, normalized_sql, first_seen)
            VALUES (?, ?, ?, ?)
            """,
          arguments: [statement.hash, statement.kind, statement.normalizedSQL, firstSeen])
      }
    }
  }

  func prune(olderThan cutoff: Date) throws {
    try database.write { db in
      try db.execute(sql: "DELETE FROM timings WHERE window_start < ?", arguments: [cutoff])
      try db.execute(sql: "DELETE FROM spans WHERE started_at < ?", arguments: [cutoff])
    }
  }

  private static func json(_ value: some Encodable) -> String {
    let encoder = JSONEncoder()
    encoder.outputFormatting = [.sortedKeys]
    guard let data = try? encoder.encode(value) else { return "null" }
    return String(decoding: data, as: UTF8.self)
  }
}
```

```swift
import Foundation

extension DBSnapshot {
  /// Counts rows in each table and reads the database and WAL file sizes. `path` is nil for
  /// in-memory databases, which report zero bytes.
  static func take(
    reader: any DatabaseReader,
    path: FilePath?,
    tables: [String] = SchemaConfiguration.baseTableNames,
    at date: Date = Date()
  ) throws -> DBSnapshot {
    let counts = try reader.read { db in
      try tables.reduce(into: [String: Int]()) { result, table in
        result[table] =
          try Int.fetchOne(db, sql: "SELECT COUNT(*) FROM \(table.quotedDatabaseIdentifier)")
          ?? 0
      }
    }

    return DBSnapshot(
      takenAt: date,
      fileBytes: fileSize(path),
      walBytes: fileSize(path.map { FilePath($0.string + "-wal") }),
      rowCounts: counts
    )
  }

  private static func fileSize(_ path: FilePath?) -> Int64 {
    guard let path, let attributes = try? FileManager.default.attributesOfItem(atPath: path.string)
    else { return 0 }

    return (attributes[.size] as? NSNumber)?.int64Value ?? 0
  }
}
```

```swift
// created on 10/26/26 by robinsr

import Foundation


/// Records performance data. Resolve with `Container.shared.metricsRecorder()`.
///
/// - Spans: low-volume named steps (e.g. one per indexing pipeline stage). Shown in
///   Instruments and persisted individually.
/// - Timings: high-volume durations (per file, per SQL statement). Aggregated per
///   `(name, tags)` per flush window.
protocol MetricsRecorder: Sendable {
  func span(_ name: StaticString, tags: MetricTags) -> MetricSpan
  func timing(_ name: String, ms: Double, tags: MetricTags)
  /// Records the text for a SQL statement hash so timings can be joined back to SQL.
  func register(statement: SQLStatementInfo)
  /// Writes buffered data now.
  func flush()
  /// Final flush and session end, waiting at most `timeout`.
  func shutdown(timeout: Duration)
}


extension MetricsRecorder {
  func span(_ name: StaticString) -> MetricSpan {
    span(name, tags: [:])
  }

  func timing(_ name: String, ms: Double) {
    timing(name, ms: ms, tags: [:])
  }

  func shutdown() {
    shutdown(timeout: .milliseconds(200))
  }

  /// Runs `body` and records its duration as a timing named `name`.
  func time<T>(_ name: String, tags: MetricTags = [:], _ body: () throws -> T) rethrows -> T {
    let start = ContinuousClock.now
    defer { timing(name, ms: start.elapsedMs, tags: tags) }
    return try body()
  }
}


/// Used when metrics are disabled, in tests, and in previews.
final class NoopMetricsRecorder: MetricsRecorder {
  func span(_ name: StaticString, tags: MetricTags) -> MetricSpan {
    SpanEmitter.silent.start(name, tags: tags, parent: nil)
  }

  func timing(_ name: String, ms: Double, tags: MetricTags) {}
  func register(statement: SQLStatementInfo) {}
  func flush() {}
  func shutdown(timeout: Duration) {}
}
```

```swift
// created on 10/26/26 by robinsr

import Foundation
import OSLog
import Synchronization
import System


typealias DBSnapshotProvider = @Sendable () throws -> DBSnapshot?


/// Remembers which statement hashes have been seen and holds new ones until the next flush.
final class StatementRegistry: Sendable {
  private struct State {
    var seen: Set<String> = []
    var pending: [SQLStatementInfo] = []
  }

  private let state = Mutex(State())

  func register(_ info: SQLStatementInfo) {
    state.withLock { state in
      if state.seen.insert(info.hash).inserted {
        state.pending.append(info)
      }
    }
  }

  func drain() -> [SQLStatementInfo] {
    state.withLock { state in
      defer { state.pending.removeAll() }
      return state.pending
    }
  }
}


final class DefaultMetricsRecorder: MetricsRecorder {
  static let defaultFlushInterval: Duration = .seconds(60)
  static let snapshotInterval: TimeInterval = 300
  static let retention: TimeInterval = 90 * 24 * 60 * 60

  let session: MetricsSession

  private let sink: any MetricsSink
  private let snapshotProvider: DBSnapshotProvider
  private let flushInterval: Duration?
  private let logFlushes: Bool
  private let logger = CustomLogger("DefaultMetricsRecorder", level: .info)

  private let aggregator = TimingAggregator()
  private let spans: SpanBuffer
  private let statements = StatementRegistry()
  private let emitter: SpanEmitter
  private let queue = DispatchQueue(label: "metrics.flush", qos: .utility)
  private let flushTask = Mutex<Task<Void, Never>?>(nil)
  private let state: Mutex<FlushState>

  private struct FlushState {
    var windowStart: Date
    var lastSnapshotAt: Date?
    var lastSnapshotId: Int64?
    var loggedFailures: Set<String> = []
  }

  /// - Parameter flushInterval: nil disables periodic flushing (tests flush manually).
  init(
    session: MetricsSession,
    sink: any MetricsSink,
    signposter: OSSignposter,
    snapshotProvider: @escaping DBSnapshotProvider,
    flushInterval: Duration? = DefaultMetricsRecorder.defaultFlushInterval,
    logFlushes: Bool = false
  ) {
    self.session = session
    self.sink = sink
    self.snapshotProvider = snapshotProvider
    self.flushInterval = flushInterval
    self.logFlushes = logFlushes
    self.state = Mutex(FlushState(windowStart: session.startedAt))

    // Built from a local: `self` can't be read until every stored property is set
    let spans = SpanBuffer()
    self.spans = spans
    self.emitter = SpanEmitter(signposter: signposter, onStop: { spans.append($0) })
  }

  /// Writes the session row, prunes old data, takes the first snapshot, and starts the
  /// periodic flush. The writes happen on the flush queue so launch isn't blocked.
  func start(now: Date = Date()) {
    queue.async { [self] in
      perform("session") { try sink.begin(session: session) }
      perform("prune") { try sink.prune(olderThan: now.addingTimeInterval(-Self.retention)) }
      takeSnapshot(at: now)
    }

    guard let interval = flushInterval else { return }

    flushTask.withLock { task in
      task = Task.detached(priority: .utility) { [weak self] in
        while !Task.isCancelled {
          try? await Task.sleep(for: interval)
          self?.flush()
        }
      }
    }
  }

  // MARK: - MetricsRecorder

  func span(_ name: StaticString, tags: MetricTags) -> MetricSpan {
    emitter.start(name, tags: tags, parent: nil)
  }

  func timing(_ name: String, ms: Double, tags: MetricTags) {
    guard ms.isFinite, ms >= 0 else { return }
    aggregator.record(name, ms: ms, tags: tags)
  }

  func register(statement: SQLStatementInfo) {
    statements.register(statement)
  }

  func flush() {
    flush(now: Date())
  }

  func shutdown(timeout: Duration) {
    flushTask.withLock { task in
      task?.cancel()
      task = nil
    }

    let done = DispatchSemaphore(value: 0)

    DispatchQueue.global(qos: .userInitiated).async { [self] in
      flush(now: Date())
      perform("session") { try sink.end(sessionId: session.id, at: Date()) }
      done.signal()
    }

    _ = done.wait(timeout: .now() + .milliseconds(Int(timeout.milliseconds)))
  }

  // MARK: - Flushing

  func flush(now: Date) {
    queue.sync {
      let timings = aggregator.drain()
      let spanRecords = spans.drain()
      let newStatements = statements.drain()

      perform("statements") { try sink.write(statements: newStatements, firstSeen: now) }
      perform("spans") { try sink.write(spans: spanRecords, sessionId: session.id) }

      guard !timings.isEmpty || !spanRecords.isEmpty else {
        state.withLock { $0.windowStart = now }
        return
      }

      if snapshotDue(at: now) {
        takeSnapshot(at: now)
      }

      let (windowStart, snapshotId) = state.withLock { state in
        defer { state.windowStart = now }
        return (state.windowStart, state.lastSnapshotId)
      }

      let windowSecs = max(1, Int(now.timeIntervalSince(windowStart).rounded()))

      perform("timings") {
        try sink.write(
          timings: timings, sessionId: session.id, snapshotId: snapshotId,
          windowStart: windowStart, windowSecs: windowSecs)
      }

      if logFlushes {
        logger.emit(.info, "Metrics flush: \(timings.count) timings, \(spanRecords.count) spans")
      }
    }
  }

  private func snapshotDue(at now: Date) -> Bool {
    state.withLock { state in
      guard let last = state.lastSnapshotAt else { return true }
      return now.timeIntervalSince(last) >= Self.snapshotInterval
    }
  }

  private func takeSnapshot(at date: Date) {
    guard let snapshot = perform("snapshot", { try snapshotProvider() }) ?? nil,
      let snapshotId = perform("snapshot", { try sink.write(snapshot: snapshot, sessionId: session.id) })
    else { return }

    state.withLock { state in
      state.lastSnapshotAt = date
      state.lastSnapshotId = snapshotId
    }
  }

  /// Runs a sink call. Failures drop the batch and are logged once per phase per session.
  @discardableResult
  private func perform<T>(_ phase: String, _ body: () throws -> T) -> T? {
    do {
      return try body()
    } catch {
      let isFirst = state.withLock { $0.loggedFailures.insert(phase).inserted }

      if isFirst {
        logger.emit(.error, "Metrics \(phase) write failed; dropping batch: \(error)")
      }

      return nil
    }
  }
}


extension DefaultMetricsRecorder {
  /// The app's recorder: `metrics.sqlite` in Application Support, signposts in Points of
  /// Interest, snapshots of the active index database. Falls back to a no-op recorder if the
  /// metrics file can't be opened.
  static func makeForApp() -> any MetricsRecorder {
    let logger = CustomLogger("Metrics", level: .info)
    let directory = AppLocation.appSupport

    try? FileManager.default.createDirectory(
      atPath: directory.string, withIntermediateDirectories: true)

    guard
      let sink = SQLiteMetricsSink.openOrRecover(
        at: directory.appending("metrics.sqlite"), logger: logger)
    else {
      return NoopMetricsRecorder()
    }

    let info = Bundle.main.infoDictionary ?? [:]
    let databasePath = IndexerContainer.shared.databasePath()

    let session = MetricsSession(
      id: UUID().uuidString,
      startedAt: Date(),
      appVersion: info["CFBundleShortVersionString"] as? String ?? "unknown",
      buildNumber: info["CFBundleVersion"] as? String ?? "unknown",
      osVersion: ProcessInfo.processInfo.operatingSystemVersionString,
      mainDbName: databasePath.baseName
    )

    let recorder = DefaultMetricsRecorder(
      session: session,
      sink: sink,
      signposter: OSSignposter(
        subsystem: Bundle.main.bundleIdentifier ?? Constants.appDisplayName,
        category: .pointsOfInterest),
      snapshotProvider: {
        let indexer = IndexerContainer.shared.indexService()
        return try DBSnapshot.take(reader: indexer.dbReader, path: databasePath)
      },
      logFlushes: RunFlags().emitMetrics
    )

    recorder.start()

    return recorder
  }
}
```

```swift
// created on 10/26/26 by robinsr

import Foundation


/// Turns SQL text into a stable key so the same statement shape aggregates together.
enum SQLNormalizer {

  /// Collapses whitespace and merges parenthesized placeholder lists, so
  /// `IN (?, ?, ?)` and `IN (?)` both become `IN (?…)`. Expects `Statement.sql` (placeholders),
  /// never `expandedSQL` (literal values).
  static func normalize(_ sql: String) -> String {
    let collapsed = sql.split(whereSeparator: \.isWhitespace).joined(separator: " ")
    return collapsed.replacing(/\(\s*\?(?:\s*,\s*\?)*\s*\)/, with: "(?…)")
  }

  static func kind(of sql: String) -> String {
    let keyword = sql.prefix { !$0.isWhitespace }.lowercased()

    switch keyword {
    case "select", "with": return "select"
    case "insert", "replace": return "insert"
    case "update": return "update"
    case "delete": return "delete"
    case "begin": return "begin"
    case "commit": return "commit"
    default: return "other"
    }
  }

  /// FNV-1a 64-bit, as 16 lowercase hex characters. Stable across launches and platforms,
  /// unlike `hashValue`.
  static func fnv1a64(_ text: String) -> String {
    var hash: UInt64 = 0xcbf2_9ce4_8422_2325

    for byte in text.utf8 {
      hash ^= UInt64(byte)
      hash = hash &* 0x0000_0100_0000_01b3
    }

    return String(format: "%016llx", hash)
  }

  static func info(for sql: String) -> SQLStatementInfo {
    let normalized = normalize(sql)
    return SQLStatementInfo(
      hash: fnv1a64(normalized), kind: kind(of: normalized), normalizedSQL: normalized)
  }
}
```

```swift
// created on 10/26/26 by robinsr

import Foundation
import GRDB
import Synchronization


/// Receives GRDB `.profile` trace events and records each statement's duration as a `sql`
/// timing tagged with the statement hash and connection kind.
///
/// The duration is SQLite's profile value: wall-clock from first step to reset, which includes
/// GRDB decoding rows between steps.
final class SQLStatementProfiler: Sendable {
  static let cacheLimit = 10_000

  private let recorder: any MetricsRecorder
  private let connection: String
  private let logToConsole: Bool
  private let logger = CustomLogger("SQLStatementProfiler", level: .debug)
  private let cache = Mutex<[String: SQLStatementInfo]>([:])

  init(recorder: any MetricsRecorder, connection: String, logToConsole: Bool = false) {
    self.recorder = recorder
    self.connection = connection
    self.logToConsole = logToConsole
  }

  func handle(_ event: Database.TraceEvent) {
    guard case let .profile(statement, duration) = event else { return }
    record(sql: statement.sql, duration: duration)
  }

  func record(sql: String, duration: TimeInterval) {
    let info = statementInfo(for: sql)
    let ms = duration * 1_000

    recorder.timing("sql", ms: ms, tags: ["stmt": info.hash, "conn": connection])

    if logToConsole {
      logger.emit(.debug, "\(String(format: "%.3f", ms))ms [\(info.hash)] \(info.normalizedSQL)")
    }
  }

  /// Normalizing runs a regex, so results are cached by raw SQL text.
  private func statementInfo(for sql: String) -> SQLStatementInfo {
    if let cached = cache.withLock({ $0[sql] }) {
      return cached
    }

    let info = SQLNormalizer.info(for: sql)

    cache.withLock { cache in
      if cache.count >= Self.cacheLimit {
        cache.removeAll()
      }
      cache[sql] = info
    }

    recorder.register(statement: info)

    return info
  }
}
```

```sql
-- HyperTagBrowser performance queries for metrics.sqlite
--
-- Open with:
--   sqlite3 -header -column ~/Library/Application\ Support/HyperTagBrowser/metrics.sqlite
-- then paste a query. Requires SQLite >= 3.38 (for ->>); macOS 15 ships 3.43+.
--
-- Bucket upper bounds (ms) by index; keep in sync with TimingBuckets.upperBoundsMs.
-- Percentiles below report the bucket upper bound that contains the percentile, so
-- "p95 <= 25ms" means 95% of calls took 25ms or less.


-- 1. Indexing pipeline breakdown, last 20 runs ------------------------------------------
WITH roots AS (
  SELECT id, started_at, duration_ms, tags
  FROM spans
  WHERE name = 'index.directory'
  ORDER BY started_at DESC
  LIMIT 20
)
SELECT
  r.started_at,
  CAST(r.tags ->> 'folder_files' AS INTEGER) AS files,
  CAST(r.tags ->> 'created' AS INTEGER) AS created,
  ROUND(r.duration_ms, 1) AS total_ms,
  ROUND(SUM(CASE WHEN c.name = 'index.list' THEN c.duration_ms END), 1) AS list_ms,
  ROUND(SUM(CASE WHEN c.name = 'index.lookup' THEN c.duration_ms END), 1) AS lookup_ms,
  ROUND(SUM(CASE WHEN c.name = 'index.relocate' THEN c.duration_ms END), 1) AS relocate_ms,
  ROUND(SUM(CASE WHEN c.name = 'index.delete' THEN c.duration_ms END), 1) AS delete_ms,
  ROUND(SUM(CASE WHEN c.name = 'index.create' THEN c.duration_ms END), 1) AS create_ms
FROM roots r
JOIN spans c ON c.parent_id = r.id
GROUP BY r.id
ORDER BY r.started_at DESC;


-- 2. Per-file indexing cost split, per session ------------------------------------------
SELECT
  s.started_at AS session,
  t.name,
  SUM(t.count) AS calls,
  ROUND(SUM(t.sum_ms), 1) AS total_ms,
  ROUND(SUM(t.sum_ms) / SUM(t.count), 3) AS avg_ms,
  ROUND(MAX(t.max_ms), 1) AS max_ms
FROM timings t
JOIN sessions s ON s.id = t.session_id
WHERE t.name IN ('fs.xattr.read', 'fs.xattr.assign') OR t.name LIKE 'index.create.%'
GROUP BY s.id, t.name
ORDER BY s.started_at DESC, total_ms DESC;


-- 3. Slowest SQL statements by p95, per 10k-row band of app_content_indices -------------
WITH bounds(idx, upper_ms) AS (
  VALUES (0, 0.05), (1, 0.1), (2, 0.25), (3, 0.5), (4, 1), (5, 2.5), (6, 5), (7, 10),
         (8, 25), (9, 50), (10, 100), (11, 250), (12, 500), (13, 1000), (14, 10000),
         (15, 1e999)
),
hist AS (
  SELECT
    t.tags ->> 'stmt' AS stmt,
    (CAST(d.row_counts ->> 'app_content_indices' AS INTEGER) / 10000) * 10000 AS rows_band,
    CAST(b.key AS INTEGER) AS idx,
    SUM(b.value) AS n
  FROM timings t
  JOIN db_snapshots d ON d.id = t.snapshot_id
  JOIN json_each(t.buckets) b
  WHERE t.name = 'sql'
  GROUP BY 1, 2, 3
),
cum AS (
  SELECT stmt, rows_band, idx,
    SUM(n) OVER (PARTITION BY stmt, rows_band ORDER BY idx) AS running,
    SUM(n) OVER (PARTITION BY stmt, rows_band) AS total
  FROM hist
),
p95 AS (
  SELECT stmt, rows_band, total, MIN(idx) AS idx
  FROM cum
  WHERE running >= 0.95 * total
  GROUP BY stmt, rows_band
)
SELECT
  p.rows_band,
  p.total AS calls,
  b.upper_ms AS p95_le_ms,
  q.kind,
  substr(q.normalized_sql, 1, 120) AS sql
FROM p95 p
JOIN bounds b ON b.idx = p.idx
LEFT JOIN sql_statements q ON q.hash = p.stmt
ORDER BY p.rows_band DESC, b.upper_ms DESC, p.total DESC
LIMIT 50;


-- 4. Statements whose p95 grew most as the database grew --------------------------------
WITH bounds(idx, upper_ms) AS (
  VALUES (0, 0.05), (1, 0.1), (2, 0.25), (3, 0.5), (4, 1), (5, 2.5), (6, 5), (7, 10),
         (8, 25), (9, 50), (10, 100), (11, 250), (12, 500), (13, 1000), (14, 10000),
         (15, 1e999)
),
hist AS (
  SELECT
    t.tags ->> 'stmt' AS stmt,
    (CAST(d.row_counts ->> 'app_content_indices' AS INTEGER) / 10000) * 10000 AS rows_band,
    CAST(b.key AS INTEGER) AS idx,
    SUM(b.value) AS n
  FROM timings t
  JOIN db_snapshots d ON d.id = t.snapshot_id
  JOIN json_each(t.buckets) b
  WHERE t.name = 'sql'
  GROUP BY 1, 2, 3
),
cum AS (
  SELECT stmt, rows_band, idx,
    SUM(n) OVER (PARTITION BY stmt, rows_band ORDER BY idx) AS running,
    SUM(n) OVER (PARTITION BY stmt, rows_band) AS total
  FROM hist
),
p95 AS (
  SELECT stmt, rows_band, MIN(idx) AS idx
  FROM cum
  WHERE running >= 0.95 * total
  GROUP BY stmt, rows_band
),
ranked AS (
  SELECT stmt, rows_band, idx,
    ROW_NUMBER() OVER (PARTITION BY stmt ORDER BY rows_band) AS first_rank,
    ROW_NUMBER() OVER (PARTITION BY stmt ORDER BY rows_band DESC) AS last_rank
  FROM p95
)
SELECT
  f.rows_band AS from_rows,
  bf.upper_ms AS from_p95_le_ms,
  l.rows_band AS to_rows,
  bl.upper_ms AS to_p95_le_ms,
  l.idx - f.idx AS buckets_grown,
  substr(q.normalized_sql, 1, 120) AS sql
FROM ranked f
JOIN ranked l ON l.stmt = f.stmt AND l.last_rank = 1
JOIN bounds bf ON bf.idx = f.idx
JOIN bounds bl ON bl.idx = l.idx
LEFT JOIN sql_statements q ON q.hash = f.stmt
WHERE f.first_rank = 1 AND l.rows_band > f.rows_band
ORDER BY buckets_grown DESC
LIMIT 25;


-- 5. User actions: average latency per 10k-row band -------------------------------------
SELECT
  t.tags ->> 'action' AS action,
  (CAST(d.row_counts ->> 'app_content_indices' AS INTEGER) / 10000) * 10000 AS rows_band,
  SUM(t.count) AS calls,
  ROUND(SUM(t.sum_ms) / SUM(t.count), 2) AS avg_ms,
  ROUND(MAX(t.max_ms), 1) AS max_ms
FROM timings t
JOIN db_snapshots d ON d.id = t.snapshot_id
WHERE t.name = 'action'
GROUP BY 1, 2
ORDER BY avg_ms DESC;


-- 6. Database growth over time ---------------------------------------------------------
SELECT
  taken_at,
  CAST(row_counts ->> 'app_content_indices' AS INTEGER) AS indices,
  CAST(row_counts ->> 'app_content_tag_items' AS INTEGER) AS tag_items,
  ROUND(file_bytes / 1048576.0, 1) AS file_mb,
  ROUND(wal_bytes / 1048576.0, 1) AS wal_mb
FROM db_snapshots
ORDER BY taken_at;
```

Create `docs/metrics/instruments.md`:

````markdown
# Profiling HyperTagBrowser with Instruments

Every metrics span (`index.directory`, `index.list`, …) is also an `os_signpost` interval in
the **Points of Interest** category, under the app's bundle identifier. Use Instruments for
"what is happening right now, and why"; use `metrics.sqlite` (`docs/metrics/queries.sql`) for
trends across sessions.

## Record a trace

1. In Xcode, choose **Product → Profile** (⌘I). This builds Release and opens Instruments.
2. Pick the **Time Profiler** template. It includes a *Points of Interest* track.
   - For signposts only, choose **Blank** and add the **os_signpost** and
     **Points of Interest** instruments with the **+** button.
3. Press record. In the app, index a folder (or do whatever feels slow).
4. Stop recording.

## Read it

- **Points of Interest track:** one bar per span. `index.directory` contains `index.list`,
  `index.lookup`, `index.relocate`, `index.delete`, `index.create` in order. The bar length is
  the duration.
- **Drill into a slow bar:** drag-select its time range in the timeline. The **Time Profiler**
  call tree below then shows only CPU samples from that range. Turn on **Invert Call Tree**
  and **Hide System Libraries** to see which of the app's functions dominate.
- **Waiting, not computing:** if a bar is long but has few CPU samples, the thread was blocked
  (disk I/O, xattrs, a lock, SQLite waiting on the writer). Add the **System Call Trace** or
  **File Activity** instrument to see what it waited on.

## What isn't in Instruments

Per-file and per-SQL-statement timings are aggregated, not signposted, to keep traces readable.
For those, see queries 2–4 in `docs/metrics/queries.sql`. For live per-statement durations,
enable the **Enable SQL Profiling** dev flag, which logs each statement's time to the console.
````
